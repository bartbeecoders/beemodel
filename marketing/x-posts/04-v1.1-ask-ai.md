```
BeeModel v1.1 "Ask AI about the selection" is out 🐝

A 3D modeller in pure x86-64 assembly. Alt+right-click an object, or pick Ask AI... in the viewport menu, and a prompt opens at the pointer.
```

**2/**

```
The AI is told what is selected: the objects, or the vertices and faces in edit mode. Bigger, Smaller, Material... and Copy Around are one click.

Only the selection is on by default. If it changes something else, BeeModel names it. Ctrl+Z takes the whole request back.
```
