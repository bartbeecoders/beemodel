UI round 2

Seven improvements to the interface before the rest of the 2.0 plan: one bug, colour picking everywhere, panels for physics and landscapes, a stronger file dialog, more themes, outliner folders and reference images.

Why now

Stages R, G and S added a solver, landscapes and shatter quickly. Most of what they can do is reachable only from the console, and the panels they did get are hand-drawn and crowded. The 2.0 plan's next stages (particles, gravity objects) would add more of the same, so the panels are done first.

Each issue is one commit on one branch, with a fakewl test that drives it by clicks, then one PR and the release.

W1 Theme selection works

Today. Preferences › Interface › Theme is a dropdown inside a dialog. ui_draw draws the dropdown list (wg_pop_draw) before the dialog (dlg_draw), and the dialog paints its dim layer and page over it. Clicks still reach the hidden list, so you click Theme, see nothing, and the next click lands on an invisible row or closes the list. Every dropdown inside a dialog has this problem: UI scale, the AI provider, the file browser's enums. The View › Theme menu and the Viewport panel's Theme field do switch the theme, but they never call prefs_save, so the choice is lost on restart.

  • Dropdown lists are drawn over dialogs, as the colour picker already is.
  • Every theme route (Preferences, View menu, Viewport panel, view.theme) goes through one theme_apply that saves the preferences.
  • The High-contrast table gets the colours it misses (field hover, focus, the UV editor).
  • Test: fakewl opens Preferences, picks Light by clicking, checks the window's pixels change and that ~/.config/beemodel/prefs holds it after a restart. The same check runs for the UI-scale dropdown.

W2 More themes

Three themes today: Dark, Light, High contrast. A theme is a table of (dark colour, its colour) pairs, so adding one is data, not code.

  • Six new themes, nine in all: Honey (warm dark, BeeModel's amber), Graphite (neutral grey, like Blender's default), Nord, Solarized Dark, Solarized Light, Dracula.
  • The theme dropdown shows a small swatch strip (background, panel, accent, text) for each theme, so you see it before you pick.
  • An accent colour preference (any theme), set with the colour picker (W3).
  • The viewport background gradient follows the theme.
  • A check that every table covers every COL_* the UI uses, so no colour is left dark in a light theme.

W3 A colour picker for every colour

A picker exists (src/colorpick.s: an SV square, a hue strip, the hex code and an eyedropper), but only material, light and texture-paint fields use it. The object colour is a #rrggbb text field, the paint form takes three 0–255 numbers, and landscape paint colours and the shatter inner colour have no field at all.

  • Every colour becomes a swatch that opens the picker: the object colour, the paint form, landscape paint layers (W5), the shatter inner colour (W4), the accent colour (W2).
  • The picker grows: R G B and H S V number fields (typing, dragging), a row of the 10 last colours used (kept in the preferences), and a row of the scene's own colours (its materials' base colours).
  • Right-click on any swatch: copy and paste the colour, reset to default.

W4 A clearer Physics panel

Properties › Physics is two halves built two ways. The rigid body half (physui.s) is hand-drawn: no tooltips, no typing, no Reset, cycle buttons instead of dropdowns, joints shown as read-only text, gravity as a single number. Only Shatter collapses, and the page is so long that fields fall out of reach under the bitmap font.

  • The whole page is rebuilt on widgets, in collapsible sections: Rigid Body, Joints, Shatter, Cloth, World, Cache. The section that applies to the object is open; the others start closed.
  • A status line at the top: Active hull body, 4.2 t, 2 joints, or Piece 12 of 80 (Wall), or Not a body with Add Rigid Body and a type and shape chosen first.
  • Dropdowns for type, shape, material preset, pattern, preset. Units on every number (kg, N/m², N·s).
  • Joints are editable: type, the other object (a picker), pivot, axis, limits, motor, break force; Add Joint right there.
  • World: gravity as a vector, steps, iterations, substeps. Body extras: start velocity, group and collide mask.
  • Shatter gains seed, spread and origin, brick size, gap and the inner colour (picker), and shows the piece and joint counts.
  • Cache: what is cached or baked (rigid, cloth), Bake and Free for each.
  • Applies to all selected objects (rigid body settings), as operators already can.

W5 A Landscape panel

Landscapes have no Properties panel. The layer stack, paint layers and rules, size and resolution, import and export, tiles and Water are reachable only from the console.

  • A Landscape tab in Properties when the active object is a landscape: size, samples, display detail, the heights' range and the last evaluation time.
  • Layers: the stack as a list (visibility, name, strength), Add (a menu of layer types), Remove, Move Up and Down. The selected layer's settings below it: noise type, seed, scale, height, octaves for Generate; droplets, rate, thermal, talus for Erode; and so on.
  • Paint: the paint layers as a list with their colour (picker), friction and bounce; the selected layer's rule (height and slope ranges); Auto Paint.
  • Water: a toggle for the sea, its level. Add › Water on its own.
  • Files: Import Heightmap, Export Heights, Export Paint, To Mesh, Split into Tiles.
  • Sculpt mode's shelf shows all eight paint materials, and its header names the landscape being sculpted.
  • Add › Landscape presets open a small form: size, samples, seed.

W6 A more powerful file dialog

The dialog's places are Home, BeeModel, / and four recent folders that are not saved. Hidden files never show, the list sorts by name only, and other drives can't be reached without typing their path.

  • The Places column gets sections: Favorites (add the current folder with a star button or by dragging a folder onto it; remove, reorder; saved in ~/.config/beemodel/places), Drives (mounted file systems from /proc/self/mounts: /run/media/$USER/*, /media, /mnt, removable and network mounts, with their free space), Recent folders (saved).
  • A breadcrumb path: each folder of the path is a button.
  • Columns: name, size, modified, sortable by clicking the header.
  • A filter box (type to narrow the list), Show hidden files (Ctrl+H), a choice of filter (the form's types or all files).
  • The preview pane shows images (PNG, JPEG, HDR) as well as .bee thumbnails.
  • Back and Forward (Alt+Left / Alt+Right).

W7 Folders in the outliner

The outliner shows objects and their parents only. There is no way to group objects without parenting them.

  • Folders: named groups of objects, nested, that never change an object's transform. A folder row has a fold arrow and its own eye, camera and lock toggles, which apply to everything inside.
  • Make one with the outliner's New Folder button, Ctrl+G (the selection into a new folder) or Object › Move to Folder (M). Drag objects and folders onto a folder to move them; drag to empty space to take them out.
  • Rename (F2, double-click), delete (the objects stay, or Delete with Contents), select all inside (double-click the icon).
  • Saved in a new optional FOLD chunk (older files open as before), undone like any change, and in the co-editing document.
  • BeeScript: folder(name [, parent]), infolder(object [, folder]), folders().

W8 Reference images

Nothing exists for modelling over a photo or a drawing.

  • Add › Reference Image... opens the file dialog (images, with W6's preview). The image comes in as a flat object at the 3D cursor, facing the view, at its aspect ratio.
  • Drawn in every shading mode, solid included: unlit, with an opacity and a choice of front / back / both sides and in front of the scene / behind it.
  • Options: show only in orthographic views, or only from its own axis (front, side, top), as in Blender; locked against selection.
  • Not rendered by default (its camera toggle off), not a collider, saved with the scene (the image embedded or linked).
  • Properties shows the image, opacity, sides, depth and visibility rules. Dropping a PNG or JPEG onto the viewport adds one.
  • BeeScript: refimage(path [, name]).

Order and risks

  • Order. W1 first (a bug, and W2 depends on it), then W2, W3 (W4 and W5 use its swatches), W4, W5, W6 (W8 uses its image preview), W7, W8, W9.
  • Binary size. The budget is 1 MiB of code (ci/check-binary.sh). Themes are tables; panels are widget descriptors, cheaper than the hand-drawn code they replace.
  • Panel height. New sections start closed so that existing tests' fields stay in reach under the bitmap font.
  • Solid-mode texturing (W8). The rasterizer has no textures today; reference images get their own unlit textured quad pass, not general texturing.
  • File format. FOLD and the reference image settings are optional chunks: older files open, older versions skip them.
